# Data Documentation for ML Modeling Team

## Overview
This document describes the parquet files generated by `data-pull.ipynb` for use in machine learning modeling. The data represents user movie interactions from a streaming platform, captured from Kafka topic `movielog8`.

## Dataset Summary
- **Data Period**: July 25, 2025 - September 22, 2025
- **Total Records Processed**: 100,000 Kafka messages
- **Users**: 287 unique users
- **Movies**: 1,075 unique movies
- **Generated Files**: 4 parquet files

---

## File Descriptions

### 1. ratings.parquet
**Purpose**: User movie ratings data
**Shape**: (629, 4)
**Source**: Parsed from Kafka messages matching pattern `/rate/{movie_id}={rating}`

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| `timestamp` | datetime64[ns] | When the rating was submitted | 2025-08-27 14:50:35 |
| `user_id` | int64 | Unique user identifier | 142245 |
| `movie_id` | object | Movie identifier (title+year format) | "a+mighty+wind+2003" |
| `rating` | int64 | User rating (1-5 scale) | 3 |

**Data Quality Notes**:
- 8 rows have invalid timestamps (NaT values)
- Rating range: 1-5 stars
- Movie IDs use `+` instead of spaces, include release year

### 2. watches.parquet
**Purpose**: Aggregated user movie watching sessions
**Shape**: (1,823, 5)
**Source**: Parsed from Kafka messages matching pattern `/data/m/{movie_id}/{minute}.mpg`, then aggregated by user-movie pairs

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| `user_id` | int64 | Unique user identifier | 770 |
| `movie_id` | object | Movie identifier (title+year format) | "the+godfather+part+ii+1974" |
| `timestamp_start` | datetime64[ns] | Start time of viewing session | 2025-09-22 04:54:28 |
| `timestamp_end` | datetime64[ns] | End time of viewing session | 2025-09-22 04:54:28 |
| `minutes_watched` | int64 | Number of unique minutes watched | 1 |

**Key Statistics**:
- Average watch duration: 54.5 minutes
- Watch duration range: 1-138 minutes
- Average movies per user: 6.4
- Average users per movie: 1.7

### 3. movies.parquet
**Purpose**: Movie metadata from external API
**Shape**: (1,075, 24)
**Source**: Fetched from `http://128.2.220.241:8080/movie/{movie_id}` for all unique movies

| Column | Type | Description |
|--------|------|-------------|
| `movie_id` | object | Primary key matching ratings/watches |
| `title` | object | Movie title |
| `tmdb_id` | int64 | The Movie Database ID |
| `imdb_id` | object | IMDb identifier |
| `release_date` | object | Release date |
| `genres` | object | JSON array of genre objects |
| `runtime` | int64 | Movie duration in minutes |
| `vote_average` | object | Average rating |
| `vote_count` | object | Number of votes |
| `budget` | object | Production budget |
| `revenue` | object | Box office revenue |
| `overview` | object | Movie synopsis |

**Additional Fields**: `original_title`, `adult`, `belongs_to_collection`, `homepage`, `original_language`, `popularity`, `poster_path`, `production_companies`, `production_countries`, `spoken_languages`, `status`

### 4. users.parquet
**Purpose**: User demographic information
**Shape**: (287, 4)
**Source**: Fetched from `http://128.2.220.241:8080/user/{user_id}` for all unique users

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| `user_id` | int64 | Primary key matching ratings/watches | 60417 |

| `occupation` | object | User occupation | "college/grad student" |
| `gender` | object | User gender (M/F) | "M" |

## Data Relationships

```
users.user_id ←→ ratings.user_id
users.user_id ←→ watches.user_id
movies.movie_id ←→ ratings.movie_id
movies.movie_id ←→ watches.movie_id
```

## Usage Notes for Modeling

### Joining Data
- Use `user_id` to join user demographics with behavioral data
- Use `movie_id` to join movie metadata with user interactions
- All movie IDs follow format: `{title}+{year}` with spaces replaced by `+`

### Data Quality Considerations
1. **Timestamps**: 8 rating records have invalid timestamps - filter these out if time-based features are needed
2. **Sparse Data**: Not all users have both ratings and watching data
3. **Watch Duration**: Some sessions show only 1 minute watched (could be false starts)
4. **Movie Metadata**: All movies have complete metadata (no nulls)

### Recommended Features
- **User Features**: Age, gender, occupation, avg_rating, total_movies_watched
- **Movie Features**: Genre, runtime, release_year, vote_average, budget
- **Interaction Features**: Rating, minutes_watched, watch_completion_rate
- **Temporal Features**: Hour_of_day, day_of_week from timestamps
